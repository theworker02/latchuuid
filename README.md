# latchuuid

Latch structured JSON uuid payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/latchuuid/

## Install / run

```bash
git clone https://github.com/theworker02/latchuuid.git
cd latchuuid
node src/cli.js
node --test
```
